# TSG Live – daily agent
Runs every morning (05:30 Zurich) on GitHub Actions: finds new real-world use cases (AI, IoT, Blockchain, RWA tokenization, Agentic AI) and the latest news, then publishes
- docs/tsg-live-data.json (use cases for the map, library and table on tsgag.com)
- docs/tsg-news.json (Live News section)
via GitHub Pages. tsgag.com loads these files on every page view.
